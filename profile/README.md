# wellsa.ai

> 프라이버시 우선 · 온디바이스 AI와 한국 공공·법률 데이터를 오픈 인프라로.

**wellsa.ai**는 개인과 조직이 자기 데이터 주권을 지키면서 AI를 활용하도록 돕습니다.
클라우드에 종속되지 않는 self-hosted AI 도구와, 흩어진 한국 공공·법률 데이터를
누구나 쓸 수 있는 **버전관리형 오픈 데이터**로 정리하는 일을 합니다.

## 🇰🇷 한국 법·규제 오픈 데이터 (Git-native)

법령·판례·규칙·행정구역을 Markdown + Git 으로 관리합니다. 각 개정·선고가 **실제 일자를 가진 commit** 이라
시점별 추적·diff·인용·RAG 에 그대로 쓸 수 있습니다.

| 저장소 | 내용 |
